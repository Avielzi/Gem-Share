## 🚀 Run Locally

### Prerequisites
- **Node.js** (v16 or higher)
- **Gemini API Key** (Get it from [Google AI Studio](https://a studio.google.com/))

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Avielzi/Gem-Share.git
   cd Gem-Share
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment**:
   Create a `.env.local` file and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Launch the app**:
   ```bash
   npm run dev
   ```
